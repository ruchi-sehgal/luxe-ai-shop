# 3 · Setup — from a fresh clone, in VS Code

## 1. Clone and open

```bash
git clone https://github.com/ruchi-sehgal/luxe-ai-shop.git
cd luxe-ai-shop
code .
```

Open the integrated terminal: `` Ctrl+` `` (or ``Cmd+` `` on Mac).

## 2. Python environment

```bash
python3 -m venv luxeenv
source luxeenv/bin/activate      # Windows: luxeenv\Scripts\activate
```

You'll know it worked when your prompt starts with `(luxeenv)`. Every
`python`/`pip` command from here on uses this isolated environment, not your
system Python.

> **macOS + python.org Python only**: if MongoDB connections later fail with
> `CERTIFICATE_VERIFY_FAILED`, run the one-time fix:
> `bash "/Applications/Python 3.x/Install Certificates.command"`
> (exact version number varies). This is a known quirk of python.org-installed
> Python on macOS, unrelated to this project's code.

## 3. Install dependencies

```bash
pip install -r requirements.txt
```

## 4. Configure environment variables

```bash
cp .env.example .env
```

Edit `.env` and fill in:

| Variable | Where to get it |
|---|---|
| `MONGO_URI` | MongoDB Atlas → your cluster → Connect → Drivers → Python. Free M0 tier is enough. Make sure Network Access allows your IP (or `0.0.0.0/0` for development). |
| `GROQ_API_KEY` *(Phase 2+)* | [console.groq.com](https://console.groq.com) → API Keys → Create API Key. Free tier. |

**Never commit `.env`** — it's already in `.gitignore`.

## 5. Seed the database (first time only)

```bash
python -m seed_data.seed
```

Reads `seed_data/bulk_upload.xlsx` and loads every row into MongoDB as a
product document. Safe to re-run — it clears and reloads the `products`
collection each time.

## 6. Run it

```bash
python -m uvicorn main:app --reload
```

Open **http://127.0.0.1:8000** — the storefront should load with real
products, images, and working category/price filters.

Interactive API docs (auto-generated by FastAPI, useful for testing
endpoints directly): **http://127.0.0.1:8000/docs**

## Troubleshooting

| Symptom | Likely cause |
|---|---|
| `ModuleNotFoundError` for an installed package | Your terminal is using the wrong Python — run `which python` / `which uvicorn` and confirm the path contains `luxeenv/bin/`. If not, re-run `source luxeenv/bin/activate` and `hash -r`. |
| `ServerSelectionTimeoutError` / `CERTIFICATE_VERIFY_FAILED` connecting to MongoDB | See the certificate note in step 2, or check Atlas Network Access allows your current IP. |
| `{"detail":"Not Found"}` on `/images/...` | Check the exact filename — case and spelling matter; compare against `static/images/`. |
| Blank product grid, no errors | Open the browser console and check the `/products` network request directly; confirm the backend is actually running. |
